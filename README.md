🌱 About the Project
Gajghor Nursery is an e-commerce website concept designed to make buying plants simple and enjoyable. Customers can discover plants by category, learn about their care requirements, add products to a cart and place orders. A dedicated administration area is planned to help the nursery owner manage products, inventory and customer orders.

🔐 Security & Responsible Development
- Keep secret keys and credentials in environment variables.
- Validate user input on both client and server where applicable.
- Protect customer and admin routes with appropriate access controls.
- Never store raw payment-card details.
- Display accurate product availability, delivery information and policies.
- Test checkout, authentication and order workflows before launch.
